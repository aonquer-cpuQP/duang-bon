# ดวงบอล

แอปวิเคราะห์ Premier League ด้วยโป๊ยยี่สี่เถ่ง ทักษาไทย สากล และราคาตลาด

| ไฟล์ | คืออะไร |
|---|---|
| `bazi-football.jsx` | **ซอร์สตัวจริง** แก้ที่ไฟล์นี้เท่านั้น |
| `duang-bon.html` | แอปที่ build แล้ว ดาวน์โหลดไปเปิดในมือถือได้เลย |
| `build/` | ชุด build — รัน `build/build.sh` แล้วได้ `duang-bon.html` ใหม่ |

`duang-bon.html` ถูกบีบอัด แกะกลับเป็นซอร์สไม่ได้ ห้ามแก้ไฟล์นี้ตรง ๆ
