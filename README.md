# ดวงบอล

แอปวิเคราะห์ Premier League ด้วยโป๊ยยี่สี่เถ่ง ทักษาไทย สากล และราคาตลาด

| ไฟล์ | คืออะไร |
|---|---|
| `bazi-football.jsx` | **ซอร์สตัวจริง** แก้ที่ไฟล์นี้เท่านั้น |
| `duang-bon.html` | แอปที่ build แล้ว ดาวน์โหลดไปเปิดในมือถือได้เลย |
| `build/` | ชุด build — รัน `build/build.sh` แล้วได้ `duang-bon.html` ใหม่ |

`duang-bon.html` ถูกบีบอัด แกะกลับเป็นซอร์สไม่ได้ ห้ามแก้ไฟล์นี้ตรง ๆ

## เครื่องมืออัพเดท

`tools/duang.py` ใช้ทั้งตอนสั่งในแชทและงานอัตโนมัติ — รัน `python3 -I tools/duang.py -h` ดูคำสั่งทั้งหมด

| คำสั่ง | ทำอะไร |
|---|---|
| `sync-fixtures` | แก้วัน/เวลาในตารางแข่งให้ตรงตารางจริง (livescore) |
| `upcoming` | นัดที่จะเตะในอีกกี่นาที — ตัวเปิดงานก่อนเตะ |
| `set-lineup` | ใส่ตัวจริง ตรวจชื่อ 11 คน และลบของเดิมของทีมนั้นก่อน |
| `prematch-odds` | ราคาก่อนเตะจาก football-data (มักอัพเดทช้า) |
| `results` | ผล ราคาปิด เตะมุม/ใบ และย้ายตัวจริงเข้าประวัติรายนัด |
| `round-status` | รอบนี้เตะครบหรือยัง |
